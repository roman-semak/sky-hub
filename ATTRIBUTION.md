# Attribution

SkyTrace is a non-commercial project. It redistributes and displays data from
the following sources.

## Live aircraft data — ODbL

- [adsb.lol](https://adsb.lol) — Open Database License (ODbL) v1.0
- [airplanes.live](https://airplanes.live) — community feed, same API contract
- [adsb.fi](https://adsb.fi) — community feed, same API contract
- [adsb.one](https://adsb.one) — community feed, same API contract
- [OpenSky Network](https://opensky-network.org) — non-commercial use only,
  used as a coverage fallback

## Static datasets

- [OurAirports](https://ourairports.com/data/) — public domain
- [OpenFlights](https://openflights.org/data) airlines — ODbL
- [Mictronics aircraft database](https://www.mictronics.de/aircraft-database/) — aircraft registrations and types

## Map and weather

- Map data © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors
- Basemap tiles © [CARTO](https://carto.com/attributions)
- Precipitation radar — [RainViewer](https://www.rainviewer.com/api.html)
- Wind aloft — [Open-Meteo](https://open-meteo.com) (CC BY 4.0)
- METAR / TAF — [NOAA Aviation Weather Center](https://aviationweather.gov)
